SAFE NEPTUNE SEO UPDATE

IMPORTANT:
- This package DOES NOT contain index.php.
- Do not change the working authentication controller.
- Back up partials_header.php and landing.php first.

From /var/www/neptune/public_html/Neptune:

sudo cp partials_header.php partials_header.php.before-seo
sudo cp landing.php landing.php.before-seo

Upload/copy the package contents into the Neptune root so these paths exist:
  partials_header.php
  landing.php
  robots.txt
  sitemap.xml
  images/neptune-og.png

Then run:
  php -l partials_header.php
  php -l landing.php
  sudo chown root:www-data partials_header.php landing.php robots.txt sitemap.xml images/neptune-og.png
  sudo chmod 664 partials_header.php landing.php robots.txt sitemap.xml images/neptune-og.png
  sudo systemctl reload apache2

Test:
  https://neptune.mckinneysteamacademy.org/
  https://neptune.mckinneysteamacademy.org/robots.txt
  https://neptune.mckinneysteamacademy.org/sitemap.xml
