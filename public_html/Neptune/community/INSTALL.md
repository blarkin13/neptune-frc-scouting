# Neptune Community Match Analysis

## Contribute in your browser

Open /community/?view=catalog, select a season, event and video, and choose a robot. Click a tag when you see an action. You can pause, replay, slow down or zoom. Even a few clear observations of one robot are useful. No account, download or helper is required. Human contributions save immediately without a review queue.

Scoring (S) marks the start of a sequence. Score estimate (O) opens a percentage slider and robot points box for the whole match. The full final alliance score, including penalties, is loaded automatically; changing either field updates the other. Estimates remain human estimates, not official per-robot scores. Reopening a robot’s estimate creates a correction while preserving the original. The remaining points are not assigned to teammates. Optional sequence details record successful counts, estimated count ranges or unknown amounts at video times; Add amount / Edit amount beside a Scoring tag edits this separate evidence. Sequence counts and whole-match estimates are not added together.

## Optional helper

/community/?view=setup provides setup instructions and Mac, Windows and Linux downloads. Helper v6.1 reads scoreboard values, clocks, results and bumper identities. It does not yet provide a validated automatic robot-action or scoring-contribution model. Its events load without signing in; starting reserved processing requires an enabled contributor account. Browser pairing handles the connection; no copied token or manually installed local AI model is needed.

Unzip and keep the folder together. On Mac, open Start Neptune Helper.command. On Windows, use Install Neptune Helper.cmd. On supported Linux, use install-neptune-helper.sh. The launchers check prerequisites. Saved drafts remain on the computer when closed. Shared models are managed centrally, not trained by each helper user.

## Learning and publication

Neptune stores public human labels, corrections and match summaries. The owner page /admin/community-learning.php runs the current experimental baseline and retains reports. Continuous tracking, a stronger video action model, automatic scoring prediction and a remote GPU training-PC connection remain development work. A candidate must be trained and independently evaluated before release. Saving labels does not automatically retrain a model.

Public video labels need no approval. Helper-generated summaries have a separate independent publication review at /community/?view=review. Unpublished drafts remain restricted to designated reviewers.

## Data and recovery

/community/training-labels.php explains and exports the current active human dataset. Account, browser and network identifiers are excluded. Missing actions and unknown counts are not zeros. Withdrawals and corrections are retained historically and excluded from active exports as appropriate.

Maintenance Console installs file updates and records self-migrations. File rollback does not erase the additive community tables or contributed labels. Back up the database separately.
